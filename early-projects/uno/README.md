# UNO

视频演示：[bilibili](https://www.bilibili.com/video/BV1nRp96yEw8/?spm_id_from=333.1387.homepage.video_card.click&vd_source=81196c19ce83679c20e55a5cf9b5a4c3)

SFML/C++ Windows 桌面小游戏。`source/UNO.exe` 已在 Windows 上完成启动验证。归档的可执行文件是测试构建，开局会自动开启 AI；双击 `source/start.bat` 后，启动器会在窗口建立后恢复为**手动模式**。

游戏中可点击 AI 按钮，或按 `Q`，在手动与 AI 托管之间切换。启动器的默认行为是手动游玩。

`source/` 同时保留 Visual Studio 工程、C++ 源码、素材与运行所需 DLL，可用于继续维护或重新编译。
