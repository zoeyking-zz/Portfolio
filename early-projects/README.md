| 项目 | 材料 | 主要限制 |
|---|---|---|
| [古堡逃杀](castle-escape/) | 项目说明、Windows 成品下载、文件清单 | 当前找到的是 IL2CPP 打包成品，不是 Unity 源工程；尚未进行启动及通关验证 |
| [Blender 实时动捕与虚拟角色工具](blender-realtime-mocap/) | 案例说明、演示关键画面 | 源码无法找回 |

| [UNO](uno/) | SFML/C++ 源码、素材、已验证的 Windows 启动文件 | Windows 桌面版；不能由 GitHub Pages 直接运行 |
| [扫雷](minesweeper/) | SFML/C++ 源码、素材、已验证的 Windows 启动文件 | Windows 桌面版；不能由 GitHub Pages 直接运行 |

每个项目保留独立 README。项目内部的 `media/`、`src/`、`Assets/` 等结构随项目一起迁移，近期开发项目不放入本目录。

网页试玩入口（启用 GitHub Pages 后）：`/early-projects/plants-vs-zombies/`。原生 SFML 项目请在 Windows 下载或克隆仓库后运行各项目 `source/` 里的 `start.bat`；它会从包含素材与动态库的正确目录启动游戏。
