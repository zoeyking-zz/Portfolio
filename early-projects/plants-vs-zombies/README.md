# 植物大战僵尸

CreateJS/Adobe Animate 导出的浏览器小游戏。部署到 GitHub Pages 后，打开本目录的 `index.html` 即可游玩，不需要 Flash、Node.js 或构建步骤。

## 在线发布

启用本仓库 GitHub Pages 后，访问：

`https://zoeyking-zz.github.io/Portfolio/games/plants-vs-zombies/`

所有脚本、贴图与库均使用相对路径，因此在仓库子目录的 GitHub Pages 地址下也能正常加载。

## 作品说明

这是一个二人合作作品。原项目说明中记录：作者主要完成战场部分的编写与对应报告，队友主要负责场景切换与对应报告。`docs/design-notes.docx` 保留原始设计说明；`.fla` 是历史 Animate 源文件，未放入此部署目录，网页运行不依赖它。
